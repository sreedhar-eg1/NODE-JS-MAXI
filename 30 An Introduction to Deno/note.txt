What is deno
    Deno is javascript runtime based on chromes v8 javascript engine

    Allows you to run javascript outside of the browser

On difference between deno and node js is deno supports both javascript and typescript
    But we can use typescript with node js also, but here there is a catch first typescript code need to be compiled to 
    javascript

Deno supports URL imports and modern javacript features like (e.g promises)

Deno is secure by default and requires explicit execution permisiions

Some actions requires permission in Deno
    we can allow permission by setting a flag while running the application
        deno run --allow-write app.ts

            --allow-write => This flag allows us to write to a file
            --allow-read => This flag allows us to read from a file

            We can configure this flag too
                --allow-write=message.txt => allows to write to message.txt file

In Node JS we have express to create server, in Deno we have Oak

Oak
    A middleware focused deno framework for building web application
    Inspired by koa JS which is build for Node Js
