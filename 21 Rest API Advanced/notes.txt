Express error handling middleware
    const error = new Error("Validation failed, entered data is incorrect.");
    error.statusCode = 422;
    throw error

    If the error handling block is not in any asynchronous code, then the express middleware catches this thrown error
    But if it in asynchronous block like than and catch, then it wont work like this
        In this case, we need to pass the error inside next
            .catch((err) => {
                if (!err.statusCode) {
                    err.statusCode = 500;
                }

                next(err);
            })

    But if we throw an error in the then block, then that error will be catched by the catch block

Authentication
    When  client send auth information to the server, the server validates and send token back to the client
    This token will be stored in the client, so the client can attach this token to all subsequent request

        This token can only be validated by the server

    TOKEN:
        JSON Data + Signature => JWT Token (JSON Web Token)
        This signature can only be verified by the server

    From front end, we add "Bearer" to the start of the token, it is just an convention to indicate that this is a JWT token
